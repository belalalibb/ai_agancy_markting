# 🧩 تفصيل المحركات والمسؤوليات (Components & Responsibilities)
**تاريخ الاعتماد:** 28 أكتوبر 2026  
**المرجعية:** دستور العائلة F0 وقرارات المعمارية D-015 و D-016

---

## 🏛️ 1. القلب التنسيقي (C0: Core Orchestrator)
- **ما يمتلكه:** إدارة هوية المستأجرين، مسارات التوجيه، تنسيق تدفق المهام عبر Temporal، سجلات التدقيق العام، وسياسات الأمان المشتركة.
- **ما يعرضه:** واجهات API الموحدة لتطبيقات الويب والجوال وواجهات التكامل الخارجية.
- **ما يستهلكه:** يستدعي المحركات E1 إلى E12 عبر عقود المغلف الموحد.
- **ما يضمنه:** عزل تام بين بيانات الشركات، وعدم تسريب الأسرار، وتوثيق بصمات المعاملات بـ SHA-256.
- **ما لا يفعله إطلاقاً:** **لا يحتوي على أي منطق تسويقي أو صناعي محدد.**

## ⚙️ 2. المحركات المتخصصة (Engines E1 - E12)

| معرف المحرك | اسم المحرك | حدوده البرمجية ومسؤوليته الحصرية | الأصول الحالية ومسار التنفيذ |
|---|---|---|---|
| **E1** | `chat-engine` | توليد النصوص، المحادثات الذكية، صياغة المنشورات والكابتشن، إعادة صياغة المحتوى، وتوجيه النماذج. | **مكتمل ومتحقق:** محول `chat_adapter` وبوابة Qevion و Groq واختبارات pytest الـ 29. |
| **E2** | `voice-engine` | تحويل الصوت إلى نص (ASR)، تحويل النص إلى صوت (TTS)، والمكالمات الهاتفية اللحظية (WebRTC/SIP). | **مخطط ومدقق:** بنية LiveKit Agents و Whisper و ElevenLabs اللحظية (D-030). |
| **E3** | `video-engine` | إنتاج وتعديل الفيديو، توليد مقاطع الريلز، دمج الصوت والترجمة، ومسار الستوك. | **جاهز معمارياً:** مسار MoneyPrinterTurbo ومحرر KrillinAI للترجمة (D-017). |
| **E4** | `data-engine` | استخراج وتطبيع البيانات، الفحص السريع للمواقع وحسابات التواصل، وتجميع العملاء المحتملين. | **منفذ جزئياً:** أدوات الفحص في `data_scraping` ودوال التحقق في `work_ai`. |
| **E5** | `knowledge-engine` | استرجاع المعرفة، البحث الهجين والفيكتوري، وذاكرة العلامة التجارية (Brand Brain). | **مخطط:** استخدام قاعدة بيانات PostgreSQL مع إضافة `pgvector`. |
| **E6** | `model-engine` | بوابة تشغيل النماذج، إدارة المفاتيح، التوجيه الذكي، ومراقبة زمن الاستجابة. | **مكتمل معمارياً:** تكامل LiteLLM Proxy مع عقد سجل المزودين (D-053). |
| **E7** | `model-factory` | جمع بيانات التدريب عالية الجودة، التقطير (Distillation)، وتوليد النماذج المتخصصة. | **مؤجل:** يتم البدء فيه بعد تجميع سجلات التجارب (Experience Records). |
| **E8** | `evaluation-engine` | التقييم الحي لجودة المحتوى المولد واكتشاف الهلوسة والامتثال لهوية البراند. | **مخطط:** فحص المخرجات بقواعد Pydantic v2 وبرومبتات مراجعة النماذج. |
| **E9** | `learning-engine` | تحليل نتائج الحملات والتفاعل وتحديث التوجيهات والاستراتيجيات تلقائياً. | **مخطط:** تحويل بيانات مؤشرات الأداء الحقيقية إلى تحسينات في الـ Brand Brain. |
| **E10** | `social-publisher` | جدولة ونشر المحتوى عبر منصات التواصل الرسمية والتحقق من حالات النشر. | **مخطط ومدروس:** طبقة مهايئات مخصصة (Custom Adapters) مبنية على وثائق المنصات الرسمية. |
| **E11** | `comms-engine` | المحادثات التفاعلية عبر واتساب، الرسائل النصية، والبريد الإلكتروني بنموذج BYOK. | **منفذ جزئياً:** نظام OmniReply AI Pro v3 المجهز بحماية ضد الحظر وتكامل Perplexity. |
| **E12** | `crm-engine` | تتبع العملاء المحتملين (Leads)، خط زمني موحد لرحلة العميل، وإدارة خطوط البيع. | **منفذ جزئياً:** المخطط والجداول في Supabase وهيكل بيانات الـ CRM في `AI_FULL`. |
