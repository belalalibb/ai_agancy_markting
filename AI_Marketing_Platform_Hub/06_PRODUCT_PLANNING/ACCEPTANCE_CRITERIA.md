# 🎯 معايير القبول وشروط الاكتمال (Acceptance Criteria & DoD)
**تاريخ التوثيق:** 28 أكتوبر 2026

---

## 📋 1. معايير القبول العامة (Definition of Done — DoD)

لكي تُعتبر أي ميزة أو شريحة برمجية "مكتملة ومقبولة" في المنظومة، يجب أن تستوفي المعايير التالية:
1. **مطابقة ميثاق الخدمة F1:** استخدام `RequestEnvelope` و `ResponseEnvelope` وتصنيف الأخطاء بدقة.
2. **الاختبارات الآلية:** اجتياز جميع اختبارات الوحدة والعقود بنسبة تغطية لا تقل عن 80%، مع نجاح كامل لاختبارات مسار الشريحة (Slice test passing).
3. **الأمان وحماية الأسرار:** خلو الكود تماماً من أي مفاتيح API أو كلمات مرور، مع اجتياز فحص `libs/explog` لحجب البيانات الحساسة.
4. **الدعم العربي الكامل:** التحقق من عرض الواجهات والمخرجات النصية باللغة العربية بشكل سليم، ودعم اتجاه النص من اليمين لليسار (RTL).
5. **التوثيق وتحديث السجلات:** توثيق أي مسار API جديد في وثائق النظام، وتحديث سجل التغييرات (`CHANGELOG.md`).
