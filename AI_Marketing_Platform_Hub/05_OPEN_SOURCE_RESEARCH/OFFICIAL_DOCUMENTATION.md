## 🔗 1. روابط وبوابات مطوري منصات التواصل الاجتماعي الرسمية

1. **Meta for Developers (Instagram & Facebook):**
   - بوابة المطورين: [https://developers.facebook.com](https://developers.facebook.com)
   - توثيق النشر على إنستغرام: [Instagram Content Publishing API](https://developers.facebook.com/docs/instagram-platform/instagram-graph-api/content-publishing)
   - متطلبات مراجعة التطبيقات: [App Review Guidelines](https://developers.facebook.com/docs/app-review)
2. **TikTok for Developers:**
   - بوابة المطورين: [https://developers.tiktok.com](https://developers.tiktok.com)
   - توثيق نشر المحتوى: [TikTok Content Posting API](https://developers.tiktok.com/doc/content-posting-api-get-started)
   - إرشادات تدقيق التطبيقات: [Audit & Verification Guide](https://developers.tiktok.com/doc/content-posting-api-faq)
3. **LinkedIn Developers:**
   - بوابة المطورين: [https://developer.linkedin.com](https://developer.linkedin.com)
   - توثيق المنشورات ومواعيد انتهاء الإصدارات: [LinkedIn Consumer Posts API](https://learn.microsoft.com/en-us/linkedin/consumer/integrations/self-serve/share-on-linkedin)
4. **X (Twitter) Developer Platform:**
   - البوابة والتسعير الجديد: [X Developer Platform & Pricing](https://developer.x.com/en/docs/twitter-api)
   - وثائق واجهة التغريد v2: [Manage Tweets API v2](https://developer.x.com/en/docs/twitter-api/tweets/manage-tweets/api-reference)
5. **YouTube Data API v3:**
   - وثائق رفع الفيديوهات: [YouTube Videos: insert API](https://developers.google.com/youtube/v3/docs/videos/insert)
